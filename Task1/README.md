Рассмотрите вертикальное и горизонтальное масштабирование для вашей системы. Оцените, какая стратегия будет эффективнее. Требуется ли использование дополнительных зон безопасности?

1. Выбор стратегии масштабирования

Выбор стратегии масштабирования зависит от того - может ли монолитное приложение core-app масштабироваться? 

В качестве стратегии масштабирования предлагаю использовать HPA + Cluster Autoscaler.


HPA используют, когда требуется автоматически масштабировать количество экземпляров приложения в ответ на изменения нагрузки, не меняя ресурсы, выделенные для каждого пода.
